# Managed IL Assembler - Fixed Issues

This table includes deliberate behavior differences as well as fixes. Defects listed here are not compatibility requirements for the IL assembler.

| Fixed issue | ilasm behavior | Managed ILASM behavior |
| --- | --- | --- |
| `#line` auto-increment | Advances only the start line on each physical newline, leaving the end line unchanged and producing reversed ranges. | Advances both line endpoints by the physical source-line delta, preserving the range and columns. The line-only form with a double-quoted file name maps the following source line to the specified line; other forms map the directive's own line to it. Includes have independent mappings, and unrepresentable effective spans are diagnosed at the directive. |
| Pseudoattribute lowering is opt-in | Automatically lowers recognized pseudo custom attributes. | Preserves custom attributes unchanged by default; `--pseudoattributes` enables lowering and the pseudoattribute-specific fixes below. |
| Partly specified `.line` end columns | Fails to assemble partly specified `.line` directives when producing a Portable PDB. | Defaults an omitted end column to `0xfffe` (65534) for compatibility with existing metadata readers; explicit end columns are preserved and validated, including the legal maximum `0xffff`. Hidden sequence points retain columns `0,0`. |
| Unencodable sequence-point line deltas | Cannot encode start-line differences outside the signed compressed integer range. | Reports `ILA0061` when the start line differs from the previous non-hidden point by less than `-0x10000000` or more than `0x0fffffff`, including across document changes and hidden points. Error-tolerant mode omits the unencodable point. |
| Invalid sequence-point coordinates | Warns and fails the method body for invalid coordinates. | Reports `ILA0061` at the `.line` or `#line` directive when producing a PDB: line and column values must fit the Portable PDB format, ranges must be ordered, and hidden points require both lines `0xFEEFEE` and columns `0,0`. Assembly fails unless error-tolerant mode is enabled; in that mode the instructions are retained but points from invalid directives are omitted, since some invalid ranges cannot be encoded. |
| `FloatingPointInstruction_ByteForms_EmitExpectedConstants` | Rejects the `bytearray` operand for floating-point constants. | Accepts byte-array forms for floating-point instruction constants. |
| `LabelBasedFilterRegion_EmitsExactExceptionRegionBounds` | Rejects the label-based filter region as undefined or structurally separated. | Emits the label-based filter region with the requested bounds. |
| `Ldtoken_NumericTokenEmittedCorrectly` | Rejects a numeric metadata token as an `ldtoken` operand. | Accepts and emits a numeric metadata token operand for `ldtoken`. |
| `ValidKeyFile_EmbedsPublicKeyAndSetsAssemblyFlag` | Reports that full signing is unsupported. | Embeds the full-signing key and sets the assembly flag. |
| `CustomAttribute_ObjectArrayWithNestedArrays_DecodesProperly` | Rejects nested attribute-array forms including `float32('a')`. | Accepts and decodes the nested attribute arrays. |
| `Typedef_CustomAttributeWithOwner_AssemblyUsePreservesOwner` | Crashes without a diagnostic. | Resolves the custom-attribute typedef and preserves its explicit assembly owner. |
| `Typedef_FieldAndCustomAttributeForms_EmitResolvableMetadata` | Crashes without a diagnostic. | Resolves the field and custom-attribute typedef forms and emits resolvable metadata. |
| `FieldAttributes_EmitExpectedFlagsAndNullConstant` | Rejects the tested `volatile` field modifier form. | Accepts the form and emits the expected field flags. |
| Duplicate field declarations | Reports a duplicate declaration with the same owner, name, and signature; omits the repeated field even with `-ERR`. | Reports `ILA0034` at each duplicate declaration and rejects normal assembly. Explicit error-tolerant mode (`-ERR` or `-ERROR`) preserves every declaration and its associated metadata. Per ECMA-335 II.22.15, `privatescope` fields are excluded from duplicate checks; different signatures or owners remain legal. |
| Native unmanaged method bodies | Refuses to compile the tested `native unmanaged` method bodies. | Accepts the method bodies and applies the tested pseudoattribute updates. |
| `DataLabelReference_MissingTarget_ReportsDiagnosticAndOmitsRelocation` | Fails without producing an output image. | Reports the missing target and emits a recoverable image without the relocation. |
| `ExportDirective_WithoutVTableFixup_DoesNotEmitNativeExportArtifacts` | Emits `.sdata`, vtable-fixup, and export directories for the unmatched `.export`. | Ignores the unmatched `.export` and omits native export artifacts. |
| `ExportOrdinal_MaxValueAsBase_EmitsSingleEntry` | Crashes without a diagnostic for an export at ordinal `int.MaxValue`. | Emits one export whose base ordinal is `int.MaxValue`. |
| `ExportOrdinal_NonPositive_ReportsDiagnosticAndOmitsExport` | Emits invalid artifacts for ordinals 0 and -1 and crashes on `int.MinValue`. | Reports non-positive ordinals and omits their exports. |
| `ExportStub_TargetMachine_IsExecutableAndRelocatable` | Rejects ARM64 exports and emits different stub layouts on supported targets. | Emits the expected executable, relocatable, target-specific export stubs. |
| `VTableFixupAndExport_UseDeclaredWritableDataAndExecutableStubs` | Places a later sparse-ordinal export stub in writable, non-executable `.sdata`. | Places every export stub in executable, non-writable `.text`, independent of ordinal gaps. |
| `Export_InvalidVTableReference_ReportsDiagnosticAndOmitsExport` | Emits fixup or export artifacts without diagnosing invalid entry or slot references. | Reports the invalid reference and omits the export. |
| `VTableEntry_InvalidAssociationWithoutExport_ReportsDiagnostic` | Emits vtable fixups without diagnosing invalid associations. | Reports the invalid associations and leaves the affected slot empty. |
| Adjacent typed data items | Rejects the second typed item in a `.data` declaration. | Accepts adjacent typed values in a `.data` declaration. |
| `VTableFixup_InsufficientDataLabelStorage_ReportsDiagnosticAndOmitsFixup` | Emits a fixup that exceeds its backing data without a diagnostic. | Reports the undersized backing storage and omits the fixup. |
| `VTableFixup_InvalidSlotCount_ReportsDiagnosticAndOmitsFixup` | Truncates or wraps invalid slot counts into emitted fixups. | Reports invalid slot counts and omits the fixup. |
| `VTableFixup_InvalidWidthForTarget_ReportsDiagnostic` | Emits a fixup with an invalid target width without a diagnostic. | Reports the invalid width and omits the fixup. |
| `VTableFixup_MissingDataLabel_ReportsDiagnosticAndOmitsFixup` | Fails without producing an output image. | Reports the missing data label and emits a recoverable image without the fixup. |
| `GenericParameterCount_OutsideMetadataIndexRange_RequiresErrorTolerant` | Silently emits more than 65,536 generic parameters and wraps their 16-bit metadata ordinals back to 0. | Reports that the generic parameter count exceeds the metadata encoding limit; only error-tolerant mode emits the wrapped metadata. |
| Generic parameter constraint owner outside the metadata index range | Silently emits a constraint owned by a generic parameter whose 16-bit metadata ordinal has wrapped. | Reports that the constraint owner index cannot be encoded; error-tolerant mode preserves the constraint for inspection. |
| `MethodGenericParameterAndConstraintDirectives_AttachCustomAttributes` | Reports an out-of-range generic parameter and a missing owner or index. | Resolves method generic parameter and constraint directives by name. |
| `MethodReferenceForms_EmitResolvableCallTokensAndMethodSpecification` | Treats the unqualified in-type call as an unresolved global reference. | Resolves the call to the method in the containing type. |
| `TypelistMscorlibAndSemicolonControls_EmitExpectedMetadata` | Leaves the implicit `System.Object` base unresolved. | Resolves the implicit object base through `mscorlib`. |
| Compiler-controlled scope disambiguator | Strips the `$PST` token-specific disambiguator from anywhere within a symbol that it is present. | Strips the `$PST` disambiguator only from the end of a symbol name, the only place ildasm adds it. |
| Parameterless pseudoattribute blob validation | Skips blob parsing for attributes with no fixed arguments or recognized named arguments, accepting malformed blobs. | Validates the prolog and named-argument count before applying the metadata transform, including for parameterless attributes. |
| Missing pseudoattribute named-argument count | Accepts a missing or truncated named-argument count as zero. | Reports a malformed blob when the required unsigned 16-bit count is missing or truncated. |
| Pseudoattribute named-argument counts with the high bit set | Interprets the count as a signed 16-bit value and skips named arguments when it is negative. | Reads the count as unsigned and reports malformed blobs when the declared arguments are missing. |
| Pseudoattribute serialization type tags | Reads each type tag as a single byte. | Uses the standard metadata blob reader's serialization type decoding, including compressed encodings. |
| Trailing bytes in pseudoattribute blobs | Does not require complete consumption of the value blob. | Reports a malformed blob when bytes remain after the declared arguments. |
| Security pseudoattributes on unsupported targets | Leaves `DynamicSecurityMethodAttribute` and `SuppressUnmanagedCodeSecurityAttribute` unchanged on targets where no transform is applied. | Reports an invalid target consistently with other recognized pseudoattributes. |
| FieldOffset pseudoattribute ordering with local references | Defers attributes with local member-reference owners or constructors, allowing them to override explicit field offsets or attributes appearing later in the source. | Applies attributes in source order regardless of reference form; explicit field offsets always take precedence. |
| `BackwardBranchOptimization_UsesShortInstructionLimit` | With `/OPTIMIZE`, leaves backward branches long when their short-form displacement is -126, -127, or -128. | Uses the actual short-form displacement and emits a short branch whenever it fits in a signed byte. |
| `ExplicitSlot_OutsideTheSixteenBitRange_IsReportedAndTakesTheNextSlot`, `NextSlot_AfterSlot65535_IsReportedAndTheLocalIsNotDeclared` | Accepts any explicit local slot: `[65536]` and above become slots that no 16-bit local instruction operand can name, and a negative slot other than `[-1]` pads the slot table toward 2^32 entries and does not finish. A local without `[n]` after one at slot 65535 takes slot 65536, which no local instruction can name either, and the PDB records its index as 0. Reads `[4294967295]` as `[-1]`, and a hexadecimal literal of more than 16 digits by its low bits, so `[0x10000000000000000]` is slot 0; neither is reported. | Reports an explicit slot outside 0 to 65535 (other than `[-1]`, which means no explicit slot) and gives the local the next free slot. The range is checked on the literal as written, so a literal too large for 32 bits is reported as well. Reports a local whose next free slot is past 65535 and does not declare it. |
| `BlockWithoutInstructions_IsReportedAtItsFirstNamedLocal`, `BlockWithoutInstructions_WithErrorTolerance_HasARowOfLengthZero`, `MethodWithoutInstructions_IsReportedAtItsFirstNamedLocal`, `MethodWithoutInstructions_WithErrorTolerance_HasARowOfLengthZero` | Writes a LocalScope row of length 0 for a `{ }` block, or a method body, that has no instructions and declares a named local; the Portable PDB specification requires a positive length. | Reports that the scope is empty; only error-tolerant mode emits the row of length 0. |
| `NameDeclaredTwiceInOneScope_IsReportedAtTheSecondDeclaration`, `NameDeclaredTwiceInOneScope_WithErrorTolerance_HasARowForEachDeclaration`, `SlotNamedTwiceInOneScope_IsReportedAtTheSecondDeclaration`, `SlotNamedTwiceInOneScope_WithErrorTolerance_HasARowForEachDeclaration`, `NamesAndSlotsDeclaredTwice_EachRepeatIsReportedAtItsDeclaration`, `NamesAndSlotsDeclaredTwice_WithErrorTolerance_HaveARowForEachDeclarationAndTheNameRefersToTheFirst`, `OneDeclarationRepeatingANameAndASlot_IsReportedForBoth` | Writes a LocalVariable row for every named local of a scope, so a scope that declares a name or a slot twice has two rows with that name or index, which the Portable PDB specification does not allow. | Reports that the local conflicts with an earlier local of the same scope; only error-tolerant mode emits the conflicting local. |
| `InstructionOnTheLineOfTheLastPointButInAnotherInputFile_GetsAPoint` | Gives an instruction a sequence point only when its lines and columns differ from the last point's, whatever the file: an instruction without a `.line` directive on the line of the last point, in another input file or an `#include`d file, gets no point and is attributed to the previous file. | Also gives the instruction a point when its document differs from the last point's. |
| `LineDirectiveBeforeAnInclude_DoesNotApplyInTheIncludedFile` | After an `#include`d file, makes the including file the current document again while the including file's `.line` coordinates stay in effect, so its next points have the coordinates of the `.line` file in the including file. | Keeps the including file's `.line` directive and its file in effect after the include. |
| `IncludedFileWithoutAPointOfItsOwn_IsNotADocument` | Defines every `#include`d file as a PDB document when it is included, whether or not any sequence point is in it. | Defines an included file as a document when one of its instructions first gets a sequence point in it. |
| `IncludedFile_IsADocumentWithTheLanguageInEffectAtItsFirstPoint` | Gives an included file's document the IL assembly language even when a `.language` directive comes right before the `#include`: it defines the document at the `#include`, before that `.language` has been applied. | Gives the document the language in effect when it is defined, at its first point. |
| `InstructionsFromADefineMacro_AreOnTheLineWhereTheMacroIsUsed` | Reads the text of a `#define` macro as a new source starting at line 1, so an instruction it produces is mapped to line 1 of the document, and all such instructions share one point. | Maps an instruction produced by a macro to the line where the macro is used. |
| `SyntaxErrorInMethod_WithErrorTolerance_PreservesValidInstructionsAndFollowingMethod` | In error-tolerant mode, a syntax error inside a method body can leave that method empty and omit the following method. | In error-tolerant mode, preserves valid instructions before and after the syntax error and preserves the following method. |
| `LinePath_UnsupportedEscapes_AreLexerErrors`, `LinePath_EscapedBackslashes_PreserveDocumentName` | Silently strips unsupported backslash escapes in a `.line` path such as `'C:\p\win.cs'`, recording `C:pwin.cs`. | The lexer reports unsupported escape sequences instead of silently stripping their backslashes. Use `'C:\\p\\win.cs'` to preserve backslashes in the document name. The same escape rules apply to double-quoted paths. |
| `LanguageDirective_SyntaxVariant_EmitsDocumentLanguage` | Ignores a `.language` GUID without braces. | Accepts both braced and unbraced GUID strings. |
| `IncludeLookup_PrefersAsWrittenThenFirstInputDirectoryThenIncludePath`, `IncludeLookup_InLaterInput_UsesFirstInputDirectory`, `NestedIncludeLookup_DoesNotFallBackToIncludingFileDirectory` | Resolves `#include` paths as written (relative to the current directory for relative paths), or through `-INCLUDE`; has no input-directory fallback. Nested includes are not relative to the including file. | Tries the path as written, then relative to the **first input file's directory**, then relative to `-INCLUDE`, in that order. Nested includes use the same search, never the including file's directory. |
