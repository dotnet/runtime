FINDING. The dominant background consumer is the agent host driving the measurement. This host
is therefore never quiet while it is being instructed, and 'idle' is not a state this machine
reaches during an agent-run session. The practical consequence is that issuing tool calls during
a measured run perturbs that run: the quiet control-suite run's invocation 8 was contaminated
(baseline 2049814 ops/s against a 2.55M mean, coarse 1385517, fine 1325752, null 2054799 - all
four arms depressed together, which is a machine-wide disturbance rather than an arm effect),
and file authoring was in progress during it. That single invocation moved the fine-arm
half-width from 2.22% at n=7 to 10.60% at n=8, and it never recovered by n=15.

METHOD CHANGE ADOPTED. Long measurement phases are launched and then left strictly alone: no
polling, no authoring, no tool calls until the completion notification arrives. This is recorded
because it changes how the numbers in this step were produced, and because 'pure authoring is
free' was an assumption that measurably was not.
